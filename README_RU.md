## Разберитесь, что происходит на сайте

Начните с недельной сводки, уточните, какие каналы изменились, затем изучите посадочные страницы или устройства. Вопрос можно уточнять в том же диалоге без ручной сборки каждого отчёта.

- **Посещаемость:** визиты, посетители, отказы, глубина просмотра и время на сайте.
- **Источники и страницы входа:** откуда приходят посетители и с каких страниц начинают визит.
- **Цели:** просмотр настроенных целей и зафиксированных достижений.
- **Сравнение периодов:** абсолютные изменения и изменения в процентах.
- **Несколько аккаунтов:** поиск доступных счётчиков подключённых аккаунтов Яндекса.
- **Углублённая диагностика:** ограниченные сводки по путям посетителей и событиям через Logs API.

Сейчас сервис работает **в режиме чтения данных аналитики и настроек счётчиков**: создание и изменение счётчиков или целей не предусмотрены. Для диагностики Logs API может создавать и очищать временные выгрузки.

## Три инструмента — подробности по запросу

MCPKit предоставляет ИИ всего три MCP-инструмента: `tool_list`, `tool_help` и `tool_execute`. ИИ может запросить каталог команд, получить подробную справку по нужной команде и выполнить её.

Полные схемы всех команд не включаются в первоначальное описание инструментов. Это экономнее использует контекст, в том числе когда вы обсуждаете другие задачи. Каталог, справка и результаты расходуют токены при запросе; фактическая экономия зависит от ИИ-клиента и диалога.


## Что спросить у ChatGPT

Примеры используют поддерживаемые отчёты и диагностику. Выберите подключённый счётчик и, когда требуется, существующую цель. Это примеры запросов, а не результаты клиентов.

| Задача | Пример запроса |
| --- | --- |
| Найти сайт | «Покажи доступные счётчики Яндекс.Метрики с сайтами и аккаунтами». |
| Недельная сводка | «Покажи визиты, посетителей и отказы по дням за последнюю завершённую неделю». |
| Разобрать изменение | «Сравни органический трафик за две завершённые недели. Какие страницы входа дали наибольшее падение?» |
| Оценить каналы | «Сравни источники трафика по визитам и достижениям цели заявки». |
| Проверить мобильный трафик | «Сравни смартфоны и компьютеры по отказам и конверсии в выбранную цель». |
| Изучить пути | «За последние три завершённых дня покажи типичные пути посетителей и поведение, связанное с целью X». |

Для разбора посадочных страниц сначала найдите страницы с заметным трафиком, затем сравните достижения целей и изменения между периодами. ИИ может предложить гипотезы для проверки; сами отчёты не доказывают причины изменений.

## Подключение без программирования

1. [Зарегистрируйтесь или войдите в MCPKit](https://mcpkit.ru/mcp-yandex-metrika). Этот же аккаунт подходит для Директа и Wordstat.
2. В [кабинете Метрики](https://mcpkit.ru/mcp-yandex-metrika/panel) подключите аккаунт Яндекса с доступом к вашим счётчикам.
3. Скопируйте адрес сервера из кабинета. Добавьте пользовательское MCP-подключение в ChatGPT, выберите **OAuth**, войдите в MCPKit и разрешите доступ.
4. Выберите подключение в чате и спросите: **«Покажи мои счётчики Яндекс.Метрики».** Затем запросите отчёт по нужному счётчику.

**Адрес MCP-сервера:** `https://mcpkit.ru/mcp-yandex-metrika/mcp`

Нужен ИИ-клиент и аккаунт с возможностью добавлять удалённые MCP-серверы через OAuth. Основные инструкции подготовлены для ChatGPT; настройка других совместимых клиентов может отличаться.

## Доступность и ограничения

Доступ к MCPKit сейчас бесплатный — условия опубликованы на [странице сервиса](https://mcpkit.ru/mcp-yandex-metrika). Возможная подписка ИИ-клиента оплачивается отдельно.

Отчёты используют данные, доступные подключённым аккаунтам. При нескольких аккаунтах укажите нужный аккаунт и счётчик. Действуют квоты API Яндекса, правила совместимости полей и семплирования; сервис сообщает о семплировании, когда оно присутствует.

Обычные отчёты выдаются постранично, до 100 строк за запрос. Диагностика Logs охватывает до 30 дней в пределах ограничений обработки и возвращает компактные результаты, а не неограниченные сырые выгрузки. Рекламный трафик не обязательно относится только к Яндекс.Директу.
